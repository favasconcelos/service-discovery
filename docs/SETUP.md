# Project Setup

## Overview
This document provides a guide for setting up the project environment for the multi-frontend workspace built using React, TypeScript, and Vite.

## Setup Steps
1. **Clone the Repository**: Clone the repository to your local machine using:
   ```bash
   git clone https://github.com/favasconcelos/service-discovery.git
   ```
2. **Navigate to the Project Directory**: Change into the project directory:
   ```bash
   cd service-discovery
   ```
3. **Install Dependencies**: Run the following command in the root directory:
   ```bash
   bun install
   ```
4. **Start Development Server**: Run the following command in the root directory:
   ```bash
   bun dev
   ```

## Conclusion
This document serves as a guide for setting up the project environment. Follow the steps to ensure a smooth setup process.
